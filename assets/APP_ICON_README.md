# Application icon

- Editable source: `app-icon.svg`
- Windows icon: `app-icon.ico`
- Generator: `generate_app_icon.py`
- Embedded sizes: 16, 32, 48, 64, 128, and 256 pixels

Regenerate from the repository root with:

    .venv/bin/python assets/generate_app_icon.py

Requirements: Python, Pillow, and `rsvg-convert`.
