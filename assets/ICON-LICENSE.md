# Application icon provenance and licensing

`app-icon.svg` is an original vector design created for the Local Time
Tracker project. It uses geometric shapes and solid colors, without
third-party artwork, stock images, fonts, or external assets.

`app-icon.ico` is generated from the SVG by `generate_app_icon.py`, using
librsvg for rendering and Pillow for ICO encoding.
