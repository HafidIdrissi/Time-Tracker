# Code of Conduct

## Our commitment

Local Time Tracker is committed to a welcoming, respectful, and
harassment-free community for everyone, regardless of background, identity,
experience, or level of technical knowledge.

## Expected behavior

- Be respectful, patient, and constructive.
- Critique ideas and code, not people.
- Assume good intent while remaining open to correction.
- Respect privacy. Never publish another person's activity data, window titles,
  reports, credentials, or identifying information.
- Keep discussions relevant and avoid spam or repeated self-promotion.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized language, personal attacks,
doxxing, deliberate intimidation, and sustained disruption are not acceptable.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may
temporarily or permanently restrict participation. Enforcement decisions will
consider context, impact, and the safety of the community.

For a confidential conduct concern, contact the maintainer using the contact
option on the [maintainer's GitHub profile](https://github.com/HafidIdrissi).
If the concern involves abuse on GitHub, use GitHub's reporting tools. Do not
open a public issue containing sensitive personal information.

This code applies to repository issues, pull requests, discussions, and other
official project spaces.
