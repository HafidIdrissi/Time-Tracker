# Roadmap

This roadmap communicates direction rather than fixed delivery dates. Priorities
may change in response to user feedback, privacy considerations, and maintainer
capacity.

## Now: strengthen the Windows foundation

- collect feedback from the first Windows users;
- improve installation and first-run guidance;
- publish clear screenshots and demonstration data;
- expand automated coverage for tracking, analytics, and reporting;
- sign public installers when a suitable Authenticode certificate is available.

## Next: privacy controls and portability

- application and title exclusion rules;
- a temporary pause or private mode that is easy to see;
- CSV or JSON data export;
- optional launch at Windows sign-in;
- system-tray controls and clearer tracking status;
- a portable Windows distribution alongside the installer.

## Later: deeper personal insights

- custom analysis date ranges;
- improved category management in the interface;
- weekly comparison summaries;
- import and backup tools;
- additional accessibility and localization work.

## Not planned by default

- mandatory accounts;
- advertising or behavioral analytics;
- uploading activity history to a publisher-operated cloud;
- employee surveillance or hidden monitoring features.

Suggestions are welcome through
[GitHub Discussions](https://github.com/HafidIdrissi/Time-Tracker/discussions).
For a concrete, reproducible request, use the feature request issue form.
