PRIVACY SUMMARY

Local Time Tracker observes the foreground Windows window and stores the
application name, window or browser-tab title, timestamps, durations, and
keyboard/mouse idle state locally.

Window titles may contain sensitive information such as document names,
searches, email subjects, account names, or private website titles.

The default installed data location is:
%LOCALAPPDATA%\LocalTimeTracker

The application has no user account, advertising, or telemetry. It does not
send activity history over the Internet.

The user can stop tracking, reset the activity history, or uninstall the
software. Reset keeps previously generated HTML reports. The official
uninstaller removes local data created by the installed application.
